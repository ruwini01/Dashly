# Dashly
A startup-focused  task planner that helps remote teams stay on track-assign tasks, plan content, check in on each other's daily progress.

## Installation (Back-End)

This project uses npm for dependency management. To install the required dependencies for Backend , run the following command in terminal:

```bash
npm install
```
create .env file in root directory and add necessary properties

```bash
PORT=XXXX
MONGO_URI=mongodb+srv://zenfivestemlink:PASSWORD@cluster0.wqdq3rg.mongodb.net/
```

## Run Backend

#### Select backend folder and open in Integrated Terminal. Run code below.
```bash
 npm run dev
```
